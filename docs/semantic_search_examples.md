# Semantic Search Examples

## How It Works

The AI-powered semantic matcher uses Gemini to intelligently understand user intent and map symptoms to ailments.

## Example Mappings

### Common Cold
- "running nose" → Common Cold
- "sneezing a lot" → Common Cold
- "stuffy nose" → Common Cold
- "congestion" → Common Cold

### Indigestion

## Multi-Match Queries

The system can also identify multiple relevant ailments:

- "cold and cough" → Common Cold, Dry Cough, Sore Throat
- "digestive problems" → Indigestion, Bloating, Acidity, Constipation
- "skin issues" → Itchy Skin, Skin Dryness, Minor Burns
